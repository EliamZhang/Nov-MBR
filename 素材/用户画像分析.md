# Wagego 新客 FPD15 用户画像分析

> 样本：6,733 名新客，FPD15 坏样本 689 名，整体坏率 10.2%。数据源：`samples_sample_with_feature_all_y_fpd15_ovd_特征分箱结果.csv`（740 个候选变量）。
>
> 说明：分箱结果只提供每个变量的边际分布，无法还原用户级交叉；以下为单变量画像，描述典型人群与高低风险人群的行为特征，不代表因果。

**一句话画像：流水干净、现金流偏薄；风险不在“有没有流水”，而在“拒付、退款/冲正、预支依赖和还款能力”。**

## 一、结论速览

- **典型客户（多数人）**：银行流水整体干净，但现金流缓冲偏薄。49.7% 的近 56 天未解决拒付占比 ≤ 0.0147（该群体坏率 6.0%，整体 10.2%）；74.6% 的工资预支未解决占比 ≤ 0.1；54.6% 的近 28 天盈余 − 负债提款落在 980–5,465。但近三成（29.8%）的用户净收入/支出比 ≤ 0.017，该群体坏率 15.2%，说明“流水干净”不等于“现金流安全”。
- **高风险客户**：呈现“拒付/退款异常 + 现金流紧张 + 依赖预支”的组合。未解决拒付占比 > 0.3191 的 5.0% 人群坏率 26.6%（lift 2.6×）；退款/冲正 ÷ 提款 > 1.25 的 9.1% 人群坏率 21.8%；工资预支未解决占比 > 0.2857 的 9.8% 人群坏率 24.4%；非 SACC 贷款占比 ≤ 0.034 的 5.0% 人群坏率 24.8%；净收入/支出比 ≤ 0.017 的 29.8% 人群坏率 15.2%。
- **低风险客户**：无拒付、低退款、正盈余、有稳定还款能力。退款/提款比 ≤ 0.017 的 41.1% 人群坏率仅 4.9%；近 28 天盈余 > 5,465 的 19.9% 人群坏率 4.4%；净收入/支出比 > 0.2221 的 9.9% 人群坏率 3.3%；非 SACC 贷款占比 > 0.7642 的 9.9% 人群坏率 3.6%；负债还款最大金额 > 1,407 的 19.9% 人群坏率 4.7%。
- **维度重要性**：拒付域 13 个变量的中位 IV 为 0.175，其中 9 个 IV≥0.1，是最强风险域；其次是盈余域（中位 0.068）和借贷机构域（中位 0.060）。余额、收入、支出域的中位 IV 仅 0.035–0.043，单独区分能力有限。
- **缺失也是画像**：退款/冲正/提款比（28天）缺失 8.8%，该群体坏率 19.8%；借贷机构预支最大金额（28天）缺失 17.5%，坏率 16.9%；BNPL 还款（近7天）缺失 54.3%，坏率 13.1%。这些缺失组的坏率高于整体，缺失本身带有风险信息。

按行为主题归纳：

- **拒付 / 未解决扣款**：借贷机构未解决拒付占比（56天，3期）。最差档 > 0.3191 坏率 26.6%（lift 2.6×，占坏客户 12.9%）；最好档 ≤ 0.0147 坏率 6.0%。
- **退款 / 冲正**：退款/冲正 ÷ 提款金额（28天）。最差档 > 1.25 坏率 21.8%（lift 2.1×，占坏客户 19.4%）；最好档 ≤ 0.017 坏率 4.9%。
- **工资预支**：工资预支未解决拒付占比（28天）。最差档 > 0.2857 坏率 24.4%（lift 2.4×，占坏客户 23.5%）；最好档 ≤ 0.1 坏率 7.2%。
- **现金流 / 盈余**：盈余 − 负债提款合计（28天）。最差档 ≤ 980 坏率 17.6%（lift 1.7×，占坏客户 42.8%）；最好档 > 5,465 坏率 4.4%。
- **收入覆盖支出**：净收入 ÷ 支出（182天）。最差档 ≤ 0.017 坏率 15.2%（lift 1.5×，占坏客户 44.4%）；最好档 > 0.2221 坏率 3.3%。
- **主流贷款使用**：非 SACC 贷款交易占比（28天）。最差档 ≤ 0.034 坏率 24.8%（lift 2.4×，占坏客户 12.0%）；最好档 > 0.7642 坏率 3.6%。
- **借贷机构预支**：借贷机构预支最大金额（近28天）。最差档 ≤ 300 坏率 17.2%（lift 1.7×，占坏客户 17.0%）；最好档 > 1,395 坏率 3.2%。
- **负债还款能力**：负债还款最大金额（84天）。最差档 ≤ 245.4 坏率 18.4%（lift 1.8×，占坏客户 17.9%）；最好档 > 1,407 坏率 4.7%。
- **交易结构**：聚合转账占比（56天）。最差档 > 0.6876 坏率 19.7%（lift 1.9×，占坏客户 9.6%）；最好档 ≤ 0.2339 坏率 5.6%。
- **账户活跃度**：借记无交易天数占比（84天）。最差档 > 0.6706 坏率 19.0%（lift 1.9×，占坏客户 16.3%）；最好档 ≤ 0.4235 坏率 6.4%。

组合起来看，高风险客户的共同点是：**近期有未解决的拒付/扣款失败，退款与冲正相对提款异常偏高，依赖工资预支和借贷机构预支，盈余与净收入覆盖不足，负债还款能力偏弱**。这类人群的坏率普遍是整体的 1.4–2.6 倍。

## 八、方法与局限

- 数据为分箱后的边际分布（6,733 人），无法做用户级交叉、聚类或联合画像；文中“组合”描述是把多个单变量结论并列，不代表同一批人同时具备。
- 坏率为样本内 FPD15 边际坏率，未控制其他变量；变量间高度相关（如拒付的 7/14/28/56/168 天窗口），单变量 lift 不能直接相加。
- 变量释义根据字段命名自动推断，需以数据字典为准；部分比率/窗口的业务含义可能与字面略有差异。
- 样本为 6,733 名有 FPD15 标签的成交新客，不代表全量戳额人群（50,291 人）；画像结论用于理解风险结构，不应直接外推到未成交人群。
- 分箱边界来自本次样本，跨期上线时需关注分布漂移与切点稳定性。
